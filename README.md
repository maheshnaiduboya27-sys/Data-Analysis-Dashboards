# Project Title : IPL Performance Analysis Dashboard using Power BI

Problem Statement : IPL data contains thousands of matches and ball-by-ball records, making it challenging to identify player performance, team success, and match trends. This project aims to build an interactive Power BI dashboard that converts raw IPL data into clear visual insights for better analysis and decision-making.

Project Objective : To analyze IPL match and player performance from 2008 to 2024 using Power BI and provide interactive insights on teams, players, batting, bowling, toss decisions, and venue performance.

Tools & Technologies Used
   -Power BI Desktop – Dashboard development and visualization
   -Power Query – Data cleaning and transformation
   -DAX (Data Analysis Expressions) – KPI and calculated measures
   -CSV Files – Data source
   -Data Modeling – Relationship between matches and deliveries tables
